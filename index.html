NumPy · Lesson 1

Arrays

NumPy is one of the foundations underneath Python's data-analysis ecosystem.

Lists versus arrays

You've already used Python lists: 

sales = [100, 200, 300, 400]

NumPy gives us arrays designed for numerical work: 

import numpy as np

sales = np.array([100, 200, 300, 400])



You can perform operations across the entire array:



sales * 2



The result is:



[200 400 600 800]

Useful operations

sales.sum()
sales.mean()
sales.min()
sales.max()
sales.std()

These become particularly useful when analysing numerical datasets.

NumPy · Lesson 2

Thinking numerically

A data analyst constantly turns raw numbers into useful measurements.

Useful statistics

values = np.array([10, 20, 30, 40, 50])

values.mean()
values.median()
values.min()
values.max()
values.std()



These answer different questions.





FunctionQuestion


mean()What is the average?


median()What is the middle value?


min()What is the smallest?


max()What is the largest?


std()How spread out are the values?
Analyst thinking: A statistic is only useful when you know what question it answers.

Example

customer_spend = np.array(
    [12, 15, 18, 19, 21, 23, 250]
)

The mean is pulled upward heavily by the £250 customer. The median gives a different picture.

This is why analysts should not automatically assume that the average tells the whole story.

pandas · Lesson 3

Loading data

Most professional analysis begins with data that already exists somewhere.

CSV files

A CSV is essentially a table stored as text. Pandas can load it into a DataFrame: 

import pandas as pd

df = pd.read_csv(“sales.csv”)



Then:



df.head()



shows the first few rows.

Other common sources

pd.read_csv("sales.csv")

pd.read_excel(“sales.xlsx”)

pd.read_json(“data.json”)



In a real job, the first question is often:
Where does the data come from?

pandas · Lesson 5

Selecting & filtering

Filtering is how you turn a huge dataset into the specific rows relevant to your question.

Selecting columns

df["revenue"]

df[[“customer”, “revenue”]]


Filtering


df[df["revenue"] > 1000]


Multiple conditions


df[
    (df["revenue"] > 1000) &
    (df["country"] == "UK")
]
Important: In pandas, use & for AND and | for OR when combining conditions.

Cleaning · Lesson 7

Missing data

Real-world data is messy. Learning how to deal with missing information is essential. 

df.isna()

df.isna().sum()



The second command tells you how many missing values exist in each column.



Removing missing rows


df.dropna()


Filling missing values


df["age"].fillna(
    df["age"].median()
)
Don't blindly delete missing data. Ask why the value is missing and whether removing or replacing it could change your analysis.

Example

If a company's customer dataset has missing income for 35% of customers, simply deleting those customers could significantly change the population you're analysing.

Cleaning · Lesson 8

Text & categories

Text data often looks simple but causes a surprising number of analytical problems.

Case differences

"UK"
"uk"
"Uk"
"UK "

A computer may treat these as different values. 

df["country"] = (
    df["country"]
    .str.strip()
    .str.upper()
)

Now values such as "uk " become "UK".

Replacing values

df["channel"] = df["channel"].replace(
    "FB",
    "Facebook"
)

Cleaning · Lesson 9

Dates

Dates unlock time-based analysis.

Convert text to dates

df["signup_date"] = pd.to_datetime(
    df["signup_date"]
)

Once pandas understands the column as dates, you can extract useful information. 

df["year"] = df["signup_date"].dt.year
df["month"] = df["signup_date"].dt.month
df["day"] = df["signup_date"].dt.day
df["weekday"] = df["signup_date"].dt.day_name()

Why dates matter

You can now ask questions such as:

  • Which month had the most sales?
  • Are customers acquired in certain months more valuable?
  • How has revenue changed over time?
  • How long after signing up do customers make their first purchase?
Transformation · Lesson 10

Calculated metrics

Raw columns are rarely enough. Analysts create metrics that answer business questions.

Revenue

df["revenue"] = (
    df["units"] * df["price"]
)

Profit

df["profit"] = (
    df["revenue"] - df["costs"]
)

Profit margin

df["margin"] = (
    df["profit"] /
    df["revenue"]
) * 100
Key idea: A good metric connects the raw data to a meaningful business question.

Analysis · Lesson 11

groupby()

This is one of the most important concepts in pandas.

The business question

Imagine your manager asks:

"How much revenue did each product generate?"

You translate that into: 

df.groupby("product")["revenue"].sum()

Or: 

df.groupby("product")["revenue"].mean()

Or: 

df.groupby("product")["revenue"].count()

Multiple metrics

df.groupby("product").agg({
    "revenue": "sum",
    "units": "sum",
    "profit": "mean"
})

Now you can compare several metrics for each product.

Analysis · Lesson 12

merge()

In real companies, information usually lives across multiple tables.

Example

customers

customer_id | name
1           | Sarah
2           | Tom
3           | Emma


orders

customer_id | revenue
1           | 500
2           | 700
1           | 250



Both tables share customer_id.
That allows us to combine them.



combined = customers.merge(
    orders,
    on="customer_id"
)






Why this is important



A company's customer information might be in one database while transactions
are in another. Marketing information may live somewhere else again.




Joining datasets is therefore a core analyst skill.

Analysis · Lesson 13

Pivot tables

Pivot tables let you summarise two dimensions of a dataset at once.

Suppose you want revenue by product AND month. 

pd.pivot_table(
    df,
    values="revenue",
    index="product",
    columns="month",
    aggfunc="sum"
)

Conceptually, you're asking: 

             Jan    Feb    Mar
Laptop       500    650    720
Phone        400    550    610
Tablet       250    310    390

This makes it much easier to compare patterns across two dimensions.

Questions pivot tables can help answer

  • Which products perform best in each region?
  • Which marketing channel performs best each month?
  • Which department has the highest costs each quarter?
  • How does customer retention vary by cohort?

Exploratory Data Analysis · Lesson 15

EDA: thinking like an analyst

Exploratory Data Analysis is where you investigate a dataset before making conclusions.

A practical EDA workflow

1. Understand the question
        ↓
2. Load the data
        ↓
3. Inspect the structure
        ↓
4. Check missing values
        ↓
5. Check duplicates
        ↓
6. Understand distributions
        ↓
7. Explore relationships
        ↓
8. Group and compare
        ↓
9. Visualise
        ↓
10. Form hypotheses

Questions to ask

  • What does each row represent?
  • What is the unit of measurement?
  • Are there suspicious values?
  • Are there outliers?
  • Which categories are largest?
  • How does the data change over time?
  • Are two variables related?
  • Could there be another explanation?
Very important: Finding a correlation is not the same as proving that one variable causes another.

The difference between coding and analysis

A programmer might ask: 

"How do I calculate the mean?"

An analyst asks: 

"Is the mean actually a useful measure
for this particular dataset?"

You're now learning the second skill.
